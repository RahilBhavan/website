Glossary

Every econometric, blockchain, and DeFi term used in this textbook, with the chapter where it first appears.

Econometric methodology
ATT Average Treatment effect on the Treated
The average causal effect of treatment, restricted to units that were actually treated. Equals $\mathbb{E}[Y(1) - Y(0) \mid D = 1]$. This project's estimand. First appears: Ch 07.
ATT(g, t)
The Callaway-Sant'Anna building block: average treatment effect for units first treated at period $g$, evaluated at calendar period $t \geq g$. First appears: Ch 09.
Bacon decomposition
Goodman-Bacon (2021) result that decomposes the TWFE coefficient under staggered treatment into a weighted average of all possible 2×2 DiD comparisons, exposing the "forbidden comparisons" where already-treated units serve as controls. First appears: Ch 08. R package: bacondecomp.
Cluster-robust standard errors (CR-SE)
Standard errors that allow arbitrary correlation among observations within a cluster (here: a token). Required for panel data; conventional CR-SEs are unreliable when the number of clusters is small (< 30). First appears: Ch 11. Reference: Cameron-Miller (2015).
Cohort (g)
The first period in which a unit was treated, used as a grouping variable in CS and SA. In our project, $g \in \{44, 68, 92, 0\}$ where $g = 0$ denotes never-treated. First appears: Ch 09.
Counterfactual
The outcome a unit would have experienced under the unobserved treatment status. Fundamentally unobservable; causal estimators are strategies for imputing it plausibly. First appears: Ch 07.
DiD Difference-in-differences
Identification strategy that compares the change in a treated unit's outcome around treatment to the change in a control unit's outcome over the same period. Identifies the ATT under parallel trends. First appears: Ch 07.
Event study
A plot of treatment-effect estimates against event time (time relative to treatment). Produced by CS's aggte(type = "dynamic"). The single most useful visualization in any DiD paper. First appears: Ch 09.
Forbidden comparison
In the Bacon decomposition: a 2×2 DiD that uses already-treated units as controls for later-treated units. Source of the TWFE bias under staggered treatment with dynamic effects. First appears: Ch 08.
HonestDiD bounds Rambachan-Roth (2023)
Robust confidence intervals that remain valid uniformly over a pre-specified set of plausible parallel-trends violations. Implemented as the HonestDiD R package. First appears: Ch 12.
IHS Inverse Hyperbolic Sine
Transform $\text{IHS}(V) = \log(V + \sqrt{V^2 + 1})$. Behaves like log for large $V$, like $V$ for small $V$, and is defined at zero. Used as the outcome variable to handle zero-inflated velocity. First appears: Ch 05.
Parallel trends assumption
The identifying assumption of DiD: the treated unit's counterfactual change would have equaled the control unit's actual change. Not directly testable; partially probed by pre-trend tests. First appears: Ch 07. Critique: Ch 12.
Placebo test
Repeated estimation of the treatment effect under random reassignment of treatment dates. The distribution of placebo estimates approximates the sampling distribution under no true effect; the actual estimate's location in this distribution gives a model-free p-value. First appears: Ch 14.
Potential outcomes
The Rubin framework: each unit has two potential outcomes $Y(1)$ and $Y(0)$, but only one is observed. The fundamental problem of causal inference is that the unobserved counterfactual is missing. First appears: Ch 07. Reference: Holland (1986).
Power (statistical)
The probability that a study will detect a true effect of a given size as statistically significant. With our N=7 sample, power for a 30% ATT is roughly 45%. First appears: Ch 13. Interactive: Fig 15.1.
Pre-trend test
Joint test of the null hypothesis that all pre-treatment event-study coefficients equal zero. Implemented as a Wald test. Roth (2022) shows that passing this test does not validate parallel trends in small samples. First appears: Ch 12.
Rademacher weights
Random ±1 weights used in the wild cluster bootstrap. Each cluster gets a single sign-flip per bootstrap iteration. Webb weights are a 6-point generalization with better small-sample properties. First appears: Ch 11.
Sun-Abraham (SA) estimator
Interaction-weighted staggered-DiD estimator that lives inside the TWFE framework: replace the single treatment dummy with a saturated set of cohort × event-time interactions. Implemented as fixest::sunab(). First appears: Ch 10. Reference: Sun & Abraham (2021).
Borusyak-Jaravel-Spiess (BJS) imputation estimator
Fit a token+time FE model on untreated observations only, predict counterfactual $\hat Y(0)$ for treated observations, take observed minus predicted as the treatment effect. R package: didimputation. First appears: Ch 10. Reference: Borusyak, Jaravel & Spiess (2024).
de Chaisemartin-D'Haultfœuille (dCDH) estimator
Cohort-specific DiD with explicit handling of treatment-effect heterogeneity; supports continuous-dose treatments natively. Implemented as the did_multiplegt Stata/R package. First appears: Ch 10. Reference: de Chaisemartin & D'Haultfœuille (2020, 2022).
Two-part hurdle model
Decomposes a zero-inflated outcome into (1) a binary Probit/logit for whether the outcome is positive and (2) an OLS (or PPML) for the magnitude conditional on positivity. Reports extensive- and intensive-margin effects separately. First appears: Ch 05. Used as robustness in Ch 14.
PPML Poisson Pseudo-Maximum Likelihood
Quasi-MLE estimator for non-negative outcomes; consistent under conditional-mean correctness without requiring the conditional variance to be Poisson. Standard choice for log-link models with zeros. First appears: Ch 05.
Webb weights
Six-point distribution $\{\pm\sqrt{1.5}, \pm 1, \pm\sqrt{0.5}\}$ used in place of Rademacher (±1) draws inside the wild cluster bootstrap. Reduces small-N discreteness artifacts in the bootstrap distribution. First appears: Ch 11. Reference: Webb (2014); Roodman et al. (2019).
CR1 small-sample correction
Multiplicative scaling factor $\frac{G}{G-1} \cdot \frac{N-1}{N-K}$ applied to the cluster-robust variance estimator to reduce its downward bias in small-cluster samples. Default in fixest. First appears: Ch 11.
Staggered treatment
Treatment that arrives in different periods for different units. The setting that breaks conventional TWFE. Our project has three staggered cohorts (OUSG → USDY → STBT). First appears: Ch 08.
TWFE Two-way fixed effects
Panel regression with unit fixed effects and time fixed effects. The canonical generalization of DiD; biased under staggered treatment with dynamic effects. First appears: Ch 07.
Wild cluster bootstrap
Inference procedure for panel data with few clusters. Repeatedly multiplies residuals by random cluster-level signs and re-fits the regression. Used with Webb weights, gives near-nominal coverage at N as small as 5. First appears: Ch 11. Reference: Roodman et al. (2019).
Winsorization
Replacing values above the $p$-th percentile with the $p$-th percentile value itself (and similarly at the bottom). Used here at the 99th percentile to dampen velocity outliers. First appears: Ch 05.
Blockchain & DeFi
AMM Automated Market Maker
On-chain exchange that uses a mathematical pricing function over two token reserves instead of an order book. Uniswap v2/v3 and Curve are the main examples relevant to this project. First appears: Ch 03.
Alchemy
RPC provider used in our pipeline. alchemy_getAssetTransfers is the high-level endpoint that returns decoded ERC-20 transfers in paginated JSON. First appears: Ch 04.
BUIDL / OUSG / USDY / BENJI / USTB / USYC / STBT
The seven tokens in our sample. See Ch 02 for per-token descriptions.
Constant product (x·y = k)
The Uniswap v1/v2 pricing invariant. Liquidity is spread uniformly across all price points from 0 to ∞ — inefficient for assets that trade in a narrow band like $1. First appears: Ch 03.
Concentrated liquidity (Uniswap v3)
LP positions are restricted to user-specified price ranges. Capital efficiency at the current price can be 100× higher than constant product for the same nominal TVL, if the range is tight. First appears: Ch 03.
ERC-20
Ethereum's token standard. Defines transfer() and emits a Transfer(from, to, value) event for every movement. First appears: Ch 04.
FFR Federal Funds Rate
The U.S. policy rate. Pulled from the FRED DFF series. Used as a time-varying macro control because tokenized Treasury demand is rate-sensitive. First appears: Ch 05.
Issuer wallet exclusion list
A hand-curated list of contract and EOA addresses operated by the token issuer or its transfer agent. Transfers involving these addresses are excluded from the "secondary" count. First appears: Ch 04.
NAV Net Asset Value
The per-token value of the fund's underlying assets. For BUIDL, USTB, STBT, USYC the NAV is held at $1.00. For OUSG and USDY it accrues upward with yield. First appears: Ch 02.
Secondary transfer
An on-chain transfer that represents genuine trading activity, as opposed to mints, burns, or issuer-internal operations. Determined by our 4-rule filter (Ch 04). First appears: Ch 04.
Stableswap (Curve)
Curve's pricing invariant, hybrid between constant-sum and constant-product. The amplification parameter $A$ controls how flat the curve is near balance. Designed for assets that trade near par. First appears: Ch 03.
Transfer agent (Securitize)
The compliance party that maintains the on-chain allowlist of approved wallets for KYC-restricted tokens. Securitize is BUIDL's transfer agent; Ondo serves the same role for its own tokens. First appears: Ch 02.
TVL Total Value Locked
The dollar value of all assets held in an AMM pool. For Curve pools, DefiLlama reports both-sides TVL; we use only the RWA side for comparability with Uniswap v3. First appears: Ch 03.
Velocity
The dependent variable: annualized secondary-transfer volume divided by average market cap. See Ch 05 for the full construction.
