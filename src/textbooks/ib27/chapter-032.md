## Chapter 26 — One-Page Tearsheet

### Learning objectives

- Compress the analysis without losing caveats.
- Select decision-useful metrics.
- Design for grayscale and print.

### Why it matters

Senior readers often begin with one page.

### Explanation

A tearsheet should include:

- transaction terms;
- ownership;
- contribution comparison;
- base/no/full synergy accretion;
- spread convention and date;
- key risks;
- sources and limitations.

The frozen tearsheet is one page according to automated page-count evidence. Grayscale readability inspection remains open.

### Project connection

The tearsheet must not imply SAMR odds, a complete PPA, or a current market view. Any spread must state **“+10.72% as of 2026-08-05 under the workbook convention; not a recommendation or forecast.”**

### Worked example

A one-page “key numbers” block:

```text
Exchange ratio: 0.3575
Announced equity value: ~$2.13bn
Ownership: 58.48% / 41.52%
Synergy guide: $35mm annual run-rate; timing and tax status qualified
FY2026E base accretion: +6.52%
FY2026E no-synergy: −7.71%
Spread: +10.72% as of 2026-08-05; not a recommendation or forecast
```

### Common mistakes

- Omitting the date from the spread.
- Overloading the page with small type.
- Using color as the only distinction.
- Treating the page as a recommendation.
- Calling automated one-page evidence a print approval.

### Checklist

- [ ] One-page automated page-count result.
- [ ] Grayscale inspection remains identified as open.
- [ ] Sources shown.
- [ ] Cases labeled.
- [ ] Caveats visible.
- [ ] Frozen spread is not presented as current.

### Takeaways

Compression should remove repetition, not evidence boundaries.
