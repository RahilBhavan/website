# Blog

Personal blog and project portfolio — Astro, MDX, Tailwind.

## Quick start

```bash
bun install
bun run dev
```

Open [http://localhost:4321](http://localhost:4321).

## Scripts

| Command | Description |
|--------|-------------|
| `bun run dev` | Start dev server |
| `bun run build` | Build for production |
| `bun run preview` | Preview production build locally |

## Stack

- [Astro](https://astro.build) 5, [MDX](https://mdxjs.com), [Tailwind](https://tailwindcss.com)
- Deploy: Vercel
- Content: `src/content/` (blog, projects)

## Project structure

- `src/pages/` — Routes (index, about, blog, projects)
- `src/content/` — Blog posts, project case studies
