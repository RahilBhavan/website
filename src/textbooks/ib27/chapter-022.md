## Chapter 18 — Comparable Companies

### Learning objectives

- Build an EV bridge.
- Calculate multiples.
- Understand peer-set limits.

### Why it matters

A comparable-company table is only useful if the numerator, denominator, period, and peer set are controlled.

### Project connection

Fiscal year ends differ, and the project documents calendarization limitations. Any workbook-specific metric whose semantics differ from conventional P/E should be cited to the exact cell and source documentation rather than generalized.

### Common mistakes

- Mixing EV and equity value.
- Mixing LTM and forward numbers.
- Treating the peer median as intrinsic value.
- Expanding the peer set silently.
- Making unsupported claims about `Comps!M11`.

### Checklist

- [ ] Six-peer scope preserved.
- [ ] EV bridge explicit.
- [ ] Fiscal periods labeled.
- [ ] Multiple definitions documented.
- [ ] Workbook-specific semantics cited directly.

### Takeaways

Comparable companies are context, not an automatic answer.
