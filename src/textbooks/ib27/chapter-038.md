## Chapter 31 — Limitations and Remaining Work

### Learning objectives

- State current blockers.
- Understand incomplete analytical modules.
- Convert limitations into a work plan.

### Why it matters

A model is more trustworthy when it says what it does not contain.

### Explanation

Remaining gaps include:

- GitHub Pages deployment remains unverified in the 2026-08-07 package.
- Excel recalculation and circular-reference inspection remain open.
- Grayscale print inspection remains open.
- Authentic recordings and oral mastery remain open.
- No complete PPA.
- No bottoms-up synergy build.
- No complete diluted-share schedule.
- No full cash-flow or balance-sheet model.
- Mid-cycle window covers only one selected broad-cycle window.
- No SAMR approval probability.
- No formal beta/event-study regression.
- No fresh-data refresh beyond the registered freezes.
- No quantified customer-overlap, qualification, or revenue-synergy evidence.

The scorecard’s “ALMOST” label and any Gate A/B/C/D/E lettering should be used only with the definitions in `research/09_qa/resume_ready_scorecard.md`. Otherwise, use the explicit status above.

### Project connection

Correct status:

> The workbook passed independent validation on 2026-08-06 but remains subject to Excel-engine recalculation.

### Worked example

A release paragraph should identify both completed evidence and open gates:

> The five canonical automated checks were run and reported their dated test, formula, invariant, and release-integrity results. Excel recalculation, grayscale print inspection, GitHub Pages verification, authentic recordings, oral mastery, and fresh-data review remain open or unverified.

### Common mistakes

- Hiding missing gates.
- Treating a limitation as zero.
- Updating a frozen date without re-running research.
- Using undefined gate lettering.

### Checklist

- [ ] List every open gate.
- [ ] Distinguish analytical and operational gaps.
- [ ] Preserve old freezes.
- [ ] Re-run QA after refresh.
- [ ] Use defined scorecard terminology only.

### Takeaways

Limitations define the valid use of the project.

### Exercises and solution references

Write a release paragraph containing three completed checks and three open gates. See `research/09_qa/resume_ready_scorecard.md`.
