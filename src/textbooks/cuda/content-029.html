9.3Recommended Reading Paths

Tailored sequences for different starting points

If you came from CPU systems engineering

You already understand caches, pipelines, and ILP. Spend most of your time on the GPU-specific bits.

SIMT → §1.3 Warps → §1.4 Memory → Ch 2 → Ch 3 (TC) → Ch 5 (cuBLAS)
If you came from ML / deep learning

You know how to use a GPU; you need to know why it works.

§0.2 Numbers → §0.3 Linalg → Ch 1 → §3.6 Numerics → §3.7 Hopper → Ch 8 (multi-GPU)
If you want to ship a CUDA kernel this week

The shortest path from zero to a benchmarkable kernel.

GEMM atom → §1.3 Threads → §1.4 Memory → Ch 2 kernels → Ch 4 profile → §5.4 benchmark
